# Phase 0 – Fundament: Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein kompilierender Cargo-Workspace mit allen Crates aus PLAN.md §3.1, einer
Qualitätsschranke `cargo xtask ci`, die Schichtung und Reinheit des Kerns maschinell erzwingt,
einem sichtbaren egui-Fenster auf Desktop und im Browser sowie CI auf GitHub für Linux, macOS,
Windows und WASM.

**Architecture:** Workspace mit `crates/*` (Bibliotheken, nach Schichten) und `apps/*`
(Programme). `xtask` ist ein internes Werkzeug-Programm (`cargo xtask ci`), dessen Prüflogik als
reine, unit-getestete Funktionen geschrieben ist. Die UI-Schicht liefert bereits eine minimale
`eframe::App`, damit der Desktop- und WASM-Pfad ab Tag 1 gebaut und in CI geprüft wird.

**Tech Stack:** Rust stable (Edition 2024, resolver 3), egui/eframe 0.36, trunk (Web-Bundle),
cargo-deny, GitHub Actions.

**Spec:** [docs/PLAN.md](../PLAN.md) – insbesondere §2 (Regeln), §3.1 (Schichten), §4
(Technologie), §7 Phase 0.

## Global Constraints

- Paketnamen: `plnwrk-core`, `plnwrk-engine`, `plnwrk-store`, `plnwrk-schedule`,
  `plnwrk-assistant`, `plnwrk-mcp`, `plnwrk-ui`, Apps `plnwrk`, `plnwrk-web`, `plnwrk-cli`.
  (Ein Crate darf nicht `core` heißen – Kollision mit Rusts eingebautem `core`.)
- Schichten: core 0 · engine 1 · store 2 · schedule 2 · assistant 3 · mcp 3 · ui 4 ·
  Apps 5. Abhängigkeit nur auf **strikt niedrigere** Schicht. `xtask` ist ausgenommen.
- Produktionscode: `unwrap`, `expect`, `panic!`, `todo!`, `unimplemented!`, unsicherer
  Indexzugriff, `unsafe` verboten (Workspace-Lints). In Tests erlaubt (`clippy.toml`).
- `plnwrk-core` und `plnwrk-engine` enthalten keine Ein-/Ausgabe, Uhrzeit, Zufall, Threads,
  Umgebungsvariablen (Reinheitsprüfung).
- WASM-fähig: core, engine, store, schedule, assistant, ui, plnwrk-web. Nur nativ: mcp,
  plnwrk, plnwrk-cli.
- Lizenz Apache-2.0. Code/Commits Englisch, Doku Deutsch.
- Commit-Trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Neuer Crate ohne Schichteintrag** → `xtask ci` muss mit klarer Meldung scheitern, nicht
   stillschweigend durchlassen (Test in Task 2).
2. **Verbotene Abhängigkeit nur als dev-dependency** (z. B. core testet mit engine) → zählt
   ebenfalls als Verstoß (Test in Task 2).
3. **Fehlendes Werkzeug** (cargo-deny, WASM-Target nicht installiert) → verständliche Meldung
   mit Installationsbefehl, kein Panic (Task 4, Funktion `require_tool`).
4. **Windows-Pfade/CRLF** im Reinheits-Scanner → Pfade über `std::path`, Zeilen über
   `str::lines()` (behandelt `\r\n`) (Test in Task 3).
5. **Verbotene Aufrufe in Kommentaren oder Doku** im Kern → Zeilen, die mit `//` beginnen,
   werden ignoriert, damit Doku den Kern erklären darf (Test in Task 3).

```rust
//! Layering rule of docs/PLAN.md §3.1: a workspace crate may depend only on workspace crates
//! in a strictly lower layer.

/// Every workspace crate and its layer. Adding a crate means adding it here.
const LAYERS: &[(&str, u8)] = &[
    ("plnwrk-core", 0),
    ("plnwrk-engine", 1),
    ("plnwrk-store", 2),
    ("plnwrk-schedule", 2),
    ("plnwrk-assistant", 3),
    ("plnwrk-mcp", 3),
    ("plnwrk-ui", 4),
    ("plnwrk", 5),
    ("plnwrk-web", 5),
    ("plnwrk-cli", 5),
];

/// Tooling crates outside the layer model.
const EXEMPT: &[&str] = &["xtask"];

pub fn layer_of(name: &str) -> Option<u8> {
    LAYERS.iter().find(|(n, _)| *n == name).map(|(_, l)| *l)
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Package {
    pub name: String,
    pub deps: Vec<String>,
}

fn is_workspace_name(name: &str) -> bool {
    name == "plnwrk" || name.starts_with("plnwrk-")
}

pub fn check(packages: &[Package]) -> Vec<String> {
    let mut errors = Vec::new();
    for package in packages {
        if EXEMPT.contains(&package.name.as_str()) {
            continue;
        }
        let Some(own) = layer_of(&package.name) else {
            errors.push(format!(
                "{} is not in the layer table (xtask/src/layers.rs); add it with its layer",
                package.name
            ));
            continue;
        };
        for dep in package.deps.iter().filter(|d| is_workspace_name(d)) {
            match layer_of(dep) {
                Some(theirs) if theirs < own => {}
                Some(theirs) => errors.push(format!(
                    "{} (layer {own}) must not depend on {dep} (layer {theirs})",
                    package.name
                )),
                None => errors.push(format!(
                    "{} depends on {dep}, which is not in the layer table",
                    package.name
                )),
            }
        }
    }
    errors
}

pub fn parse_metadata(json: &str) -> Result<Vec<Package>, String> {
    let value: serde_json::Value =
        serde_json::from_str(json).map_err(|e| format!("cargo metadata: {e}"))?;
    let packages = value
        .get("packages")
        .and_then(|p| p.as_array())
        .ok_or("cargo metadata: no packages array")?;
    packages
        .iter()
        .map(|p| {
            let name = p
                .get("name")
                .and_then(|n| n.as_str())
                .ok_or("cargo metadata: package without name")?;
            let deps = p
                .get("dependencies")
                .and_then(|d| d.as_array())
                .map(|deps| {
                    deps.iter()
                        .filter_map(|d| d.get("name").and_then(|n| n.as_str()))
                        .map(String::from)
                        .collect()
                })
                .unwrap_or_default();
            Ok(Package { name: name.to_owned(), deps })
        })
        .collect()
}
```

```rust
//! Purity rule of docs/PLAN.md §2: core and engine take no input from the outside world.

use std::path::Path;

/// Source folders that must stay pure.
pub const PURE_CRATES: &[&str] = &["crates/core/src", "crates/engine/src"];

const FORBIDDEN: &[(&str, &str)] = &[
    ("std::fs", "file system"),
    ("std::net", "network"),
    ("std::process", "processes"),
    ("std::env", "environment"),
    ("std::thread", "threads"),
    ("SystemTime", "wall clock"),
    ("Instant::now", "clock"),
    ("rand::", "randomness"),
];

pub fn scan(path: &Path, contents: &str) -> Vec<String> {
    let mut found = Vec::new();
    for (index, line) in contents.lines().enumerate() {
        if line.trim_start().starts_with("//") {
            continue;
        }
        for (pattern, what) in FORBIDDEN {
            if line.contains(pattern) {
                found.push(format!(
                    "{}:{}: {what} ({pattern}) is not allowed in a pure crate",
                    path.display(),
                    index + 1
                ));
            }
        }
    }
    found
}
```

```rust
//! The quality gate. Each step prints its name and stops the gate on failure.

use std::path::{Path, PathBuf};
use std::process::Command;

use crate::{layers, purity};

/// Crates that must build for the browser (docs/PLAN.md §2, §3.1).
const WASM_CRATES: &[&str] = &[
    "plnwrk-core",
    "plnwrk-engine",
    "plnwrk-store",
    "plnwrk-schedule",
    "plnwrk-assistant",
    "plnwrk-ui",
    "plnwrk-web",
];

fn root() -> PathBuf {
    Path::new(env!("CARGO_MANIFEST_DIR"))
        .parent()
        .map(Path::to_path_buf)
        .unwrap_or_else(|| PathBuf::from("."))
}

fn step(name: &str) {
    eprintln!("\n== {name}");
}

fn cargo(args: &[&str]) -> Result<(), String> {
    let status = Command::new(env!("CARGO"))
        .args(args)
        .current_dir(root())
        .status()
        .map_err(|e| format!("cannot run cargo {}: {e}", args.join(" ")))?;
    if status.success() {
        Ok(())
    } else {
        Err(format!("cargo {} failed", args.join(" ")))
    }
}

fn require_tool(probe: &[&str], install: &str) -> Result<(), String> {
    let ok = Command::new(env!("CARGO"))
        .args(probe)
        .output()
        .map(|o| o.status.success())
        .unwrap_or(false);
    if ok { Ok(()) } else { Err(format!("missing tool; install it with: {install}")) }
}

pub fn layers() -> Result<(), String> {
    step("layering");
    let output = Command::new(env!("CARGO"))
        .args(["metadata", "--format-version", "1", "--no-deps"])
        .current_dir(root())
        .output()
        .map_err(|e| format!("cannot run cargo metadata: {e}"))?;
    let json = String::from_utf8(output.stdout).map_err(|e| e.to_string())?;
    let errors = layers::check(&layers::parse_metadata(&json)?);
    report(errors)
}

pub fn purity() -> Result<(), String> {
    step("purity of core and engine");
    let mut errors = Vec::new();
    for dir in purity::PURE_CRATES {
        collect_rs(&root().join(dir), &mut |path, contents| {
            errors.extend(purity::scan(path, contents));
        })?;
    }
    report(errors)
}

fn collect_rs(dir: &Path, visit: &mut dyn FnMut(&Path, &str)) -> Result<(), String> {
    let entries = std::fs::read_dir(dir).map_err(|e| format!("{}: {e}", dir.display()))?;
    for entry in entries {
        let path = entry.map_err(|e| e.to_string())?.path();
        if path.is_dir() {
            collect_rs(&path, visit)?;
        } else if path.extension().is_some_and(|e| e == "rs") {
            let contents =
                std::fs::read_to_string(&path).map_err(|e| format!("{}: {e}", path.display()))?;
            visit(&path, &contents);
        }
    }
    Ok(())
}

fn report(errors: Vec<String>) -> Result<(), String> {
    if errors.is_empty() {
        return Ok(());
    }
    for error in &errors {
        eprintln!("  {error}");
    }
    Err(format!("{} violation(s)", errors.len()))
}

pub fn all() -> Result<(), String> {
    step("format");
    cargo(&["fmt", "--all", "--check"])?;
    layers()?;
    purity()?;
    step("clippy (native)");
    cargo(&["clippy", "--workspace", "--all-targets", "--locked", "--", "-D", "warnings"])?;
    step("clippy (wasm32)");
    let mut wasm = vec!["clippy", "--target", "wasm32-unknown-unknown", "--locked"];
    for krate in WASM_CRATES {
        wasm.extend(["-p", krate]);
    }
    wasm.extend(["--", "-D", "warnings"]);
    cargo(&wasm)?;
    step("tests");
    cargo(&["test", "--workspace", "--locked"])?;
    step("dependencies (cargo-deny)");
    require_tool(&["deny", "--version"], "cargo install --locked cargo-deny")?;
    cargo(&["deny", "--all-features", "check"])?;
    eprintln!("\nall gates passed");
```
